SpecSWD documentation

SpecSWD computes surface-wave dispersion, eigenfunctions, and sensitivity kernels in layered elastic, acoustic, anisotropic, and attenuating media.

The Python interface uses NumPy arrays. Variable mode counts are represented with CSR containers and stored in a versioned HDF5 schema that is shared with the C++ interface.
