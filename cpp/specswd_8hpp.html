void specswd_group_kl ( int imode,
Real * frekl_c,
Real * frekl_q )

compute group kernels

Parameters
imodewhich mode return, =0 is fundamental
frekl_cfrechet kernels for group velocity, size = (nker,nz), user memory management
frekl_qfrechet kernels for group velocity, size = (nker,nz), user memory management. it will not be used for elastic case
Note
nker dependents on : 1.elastic love, nker = 3 vsh/vsv/rho
  1. visco-elastic love, nker = 5 vsh/vsv/QNi/QLi/rho
  2. elastic rayleigh nker = 6 vph/vpv/vsv/eta/vp/rho
  3. visco-elastic rayleigh nker = 10 vph/vpv/vsv/eta/Qai/Qci/Qli/vp/Qki/rho
