Detailed Description

Ragged dispersion values on a frequency/azimuth grid.

Phase and group data have independent CSR structures so callers may save different mode selections for the two observables. Solve-point rows use azimuth as the inner dimension: row = frequency_index*n_azimuth + azimuth_index.
