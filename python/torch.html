PyTorch API reference

Install the optional backend with python -m pip install '.[torch]' and import it from specd.torch. It runs without the native extensions. See PyTorch backend for model conventions, differentiation, kernel units, and runnable examples.

Independent PyTorch implementation of the SpecSWD spectral solver.

Model tensors retain their graphs. Non-tensor inputs become float64 leaf tensors requiring gradients, accessible through parameters. Geometry, adaptive element counts, interpolation locations and mode selection are discrete, fixed decisions during differentiation.

group_velocity()[source]

All modes at once using operator JVPs and eigenvalue perturbation.

For P(k,f)r=0, dk/df = -(l^H P_f r)/(l^H P_k r). Forward-mode autodiff computes the operator partials without one eigensolver backward per mode. Keeping the eigenvectors in the graph supports group kernels.

kernels(imode=0, *, observable='phase', component='real', create_graph=False)[source]

Return named autograd derivatives on the original model grid.

Q derivatives here are d/dQ. get_phase_kl and get_group_kl convert these to d/d(Q^-1), matching the native kernel convention. Anisotropic group kernels use the radial group component.
